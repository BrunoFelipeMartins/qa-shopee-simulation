# Requisitos Funcionais - Simulação Shopee

1. O sistema deve permitir que o usuário pesquise produtos.
2. O sistema deve exibir detalhes do produto (nome, preço, descrição, imagens).
3. O sistema deve permitir adicionar produtos ao carrinho.
4. O sistema deve recalcular o total ao alterar quantidades.
5. O sistema deve permitir finalizar a compra.
