# Requisitos Funcionais - Simulação Shopee

## Catálogo e Produto
1. O sistema deve permitir que o usuário pesquise produtos por nome, categoria ou filtro.  
2. O sistema deve exibir a página de detalhes do produto (nome, preço, descrição, imagens e avaliações).  
3. O sistema deve atualizar o valor total quando o usuário selecionar variações do produto (ex.: cor ou tamanho).  

## Carrinho de Compras
4. O sistema deve permitir que o usuário adicione produtos ao carrinho.  
5. O sistema deve permitir que o usuário altere a quantidade de produtos no carrinho.  
6. O sistema deve recalcular o total automaticamente ao alterar quantidades ou remover itens.  

## Checkout
7. O sistema deve permitir que o usuário selecione o endereço de entrega ou cadastre um novo.  
8. O sistema deve permitir a escolha do método de entrega (padrão, expresso, frete grátis quando disponível).  
9. O sistema deve exibir o valor do frete e o total do pedido antes da finalização.  

## Pagamento
10. O sistema deve permitir selecionar métodos de pagamento (cartão, Pix, boleto, carteira ShopeePay).  
11. O sistema deve validar os dados do pagamento.  
12. O sistema deve exibir mensagem de confirmação ao finalizar a compra.  

## Pós-Compra
13. O sistema deve enviar e-mail ou notificação de confirmação de pedido.  
14. O usuário deve poder visualizar o status do pedido na área "Meus pedidos".
