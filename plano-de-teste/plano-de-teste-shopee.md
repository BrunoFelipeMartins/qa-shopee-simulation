# Plano de Teste - Simulação Shopee

## 1. Objetivo
Validar o fluxo de compra de um produto na Shopee, garantindo que o usuário consiga pesquisar, adicionar ao carrinho e finalizar o pedido com sucesso.

## 2. Escopo
- Pesquisa de produtos  
- Carrinho de compras  
- Checkout e pagamento  

## 3. Tipos de Teste
- Teste funcional  
- Teste de interface  
- Teste exploratório  
- Teste de regressão (simulado)  

## 4. Ambiente de Teste
- Plataforma: Web (Shopee.com.br)  
- Navegador: Google Chrome 128+  
- Sistema operacional: Windows 10+  

## 5. Ferramentas
- GitHub (documentação e versionamento)  
- Excel (casos de teste)  
- Capturas de tela (evidências) 

## 6. Critérios de Aceite
- O fluxo de compra é concluído sem erros.  
- O cálculo do total (produto + frete) é correto.  
- O status do pedido é exibido corretamente.  

## 7. Riscos e Restrições
- O site real da Shopee pode mudar a qualquer momento.  
- Algumas ações podem exigir login real do usuário.
