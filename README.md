# Projeto QA - Simulação Shopee

Este projeto foi criado para demonstrar habilidades em **testes manuais**, **planejamento de testes** e **documentação QA**.  
A simulação é inspirada no **fluxo de compra da Shopee**, cobrindo desde a pesquisa até o pagamento.

## Estrutura
- **/requisitos** → Requisitos funcionais do sistema  
- **/planos-de-teste** → Plano de teste detalhado  
- **/casos-de-teste** → Casos de teste organizados  
- **/bugs** → Relatórios de bugs encontrados  
- **/evidencias** → Prints e comprovações de execução  

## Ferramentas
- Markdown / GitHub  
- Excel (para casos de teste)  
- Capturas de tela para evidências  
- Navegador Chrome  

---

>  Este projeto é apenas uma simulação educacional, criada para fins de portfólio e estudo de QA.
